# 目标

把"全杀命令"拦截模式同步进仓库默认配置与文档（1.6 生产配置已于 2026-09-22 紧急打上其中 3 条），并补齐上一轮（gateway-usability）遗漏同步到文档的 2 条黑名单，使仓库默认、文档、生产三处一致。

# 范围

- config.json 默认黑名单追加 3 条（今天已在 1.6 生产验证拦截）：
  - `pkill -f ""` 空模式全杀：`pkill\s+(-[a-zA-Z0-9]+\s+)*-f\s+(['\"]{0,2})\s*$`
  - `kill -1` / `kill -9 -1` 全杀：`\bkill\s+(-9\s+)?-1\b`
  - `kill -- -1` 变体：`\bkill\s+--\s+-1\b`
- README config.json 示例同步 5 条（上述 3 条 + gateway-usability 轮的 `dd of=/dev/sd*`、`chmod -R 777 /`）；
- docs/使用说明.md §7.4 黑名单表格补 4 行（dd of= 变体、chmod -R 777 /、pkill 空模式、kill 全杀）；
- docs/开发需求文档.md FR5 默认覆盖清单文字扩展；
- 生产 1.6 配置补 gateway-usability 轮遗漏的 2 条（dd of=、chmod -R 777 /），重启验证，使生产=仓库 10 条。
